페이지 안내사항

바다비 팬 제작 노래책은 팬이 직접 만든 비공식 팬 사이트입니다.
바다비 공식 사이트나 공식 운영 채널이 아니며, 팬들을 위해 노래 목록과 관련 정보를 편하게 볼 수 있도록 만든 팬 사이트입니다.

  • 노래 목록이나 사이트 내용에 수정하거나 추가했으면 하는 내용이 있다면 팬카페를 통해 알려주세요.
  • 관리자 로그인을 사용하는 경우, 다음에 다시 방문했을 때 로그인 상태를 유지할 수 있도록 로그인에 필요한 정보가 사용자의 브라우저에 저장될 수 있습니다.
  • 로그인 보안을 위해 Cloudflare Turnstile을 사용하여 자동 프로그램이나 봇에 의한 비정상적인 로그인 시도를 확인합니다.
  • 반복적인 로그인 실패를 막기 위해 브라우저에 개인을 직접 알아볼 수 없는 임의의 식별값이 만들어질 수 있습니다. 이 값은 이름이나 연락처 등을 확인하기 위한 것이 아니며, 로그인 제한을 위해 IP 주소를 별도의 식별값으로 저장하는 방식은 사용하지 않습니다.
  • 관리자 로그인에 사용하는 비밀번호 자체는 공개된 사이트에 저장하지 않습니다. 로그인에 성공하면 비밀번호 대신 별도의 보안 토큰을 사용하여 로그인 상태를 유지합니다.
  • 사이트의 안정적인 운영과 보안을 위해 Cloudflare 등의 서비스를 이용하며, 사이트를 이용하는 과정에서 접속·보안·서비스 운영에 필요한 정보가 해당 서비스의 정책에 따라 처리될 수 있습니다.
  • 사이트의 기능이나 내용은 운영 상황에 따라 별도의 안내 없이 변경되거나 수정될 수 있습니다.
